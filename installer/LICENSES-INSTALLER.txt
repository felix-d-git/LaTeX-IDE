Node.js
-------
Windows: wird als vorkompilierte Binary mitgeliefert (Ordner "node\").
Lizenz: MIT (Node.js selbst); node\LICENSE enthaelt ausserdem die Lizenzen
der eingebauten Komponenten, u. a. OpenSSL (Apache-2.0), ICU (Unicode
License V3), V8, libuv und npm (Artistic License 2.0).
macOS: wird NICHT mitgeliefert. install.command laedt das offizielle
Node.js-Paket von https://nodejs.org/ (SHA256-geprueft); dessen Lizenz
liegt danach unter ~/Applications/LatexIDE/node/LICENSE.

TeX Live / MacTeX / Tectonic
----------------------------
Wird NICHT mitgeliefert. LatexIDE ruft das TeX-System nur als externes
Programm ueber den PATH auf (Standard: latexmk); TEX_BACKEND=tectonic
waehlt stattdessen Tectonic (nur Desktop-App, separat zu installieren).
Fehlt ein TeX-System, laedt der Installer TeX Live (Windows) bzw. MacTeX
(macOS) waehrend der Installation direkt von einem offiziellen
CTAN-/TUG-Spiegelserver (ftp.tu-chemnitz.de, historisches TeX Live 2025)
herunter und installiert es lokal. TeX Live/MacTeX stehen unter freien
Lizenzen der jeweiligen Pakete (ueberwiegend LPPL, teils andere freie
Lizenzen); Details siehe https://www.tug.org/texlive/LICENSE.TL bzw.
die Lizenzdateien innerhalb der TeX-Live-Installation.
